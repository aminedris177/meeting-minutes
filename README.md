# Meeting Follow-up — محاضر الاجتماعات والمتابعة

تطبيق موبايل (PWA) لإدارة الاجتماعات المتكررة: الحضور، المحاور، متابعة المهام، القرارات، وتصدير المحضر Word وPDF.

- **يعمل بدون إنترنت** بعد أول فتح.
- **كل البيانات على الموبايل فقط.** مفيش سيرفر ولا حسابات ولا أي إرسال للبيانات.
- الكود ده عام ومفيهوش أي بيانات حقيقية.

---

## 1. الرفع على GitHub وتفعيل Pages

1. اعمل repo جديد على GitHub باسم **`meeting-minutes`**، ويكون عام (Public).
2. من جهازك، جوه فولدر المشروع:
   ```bash
   git remote add origin https://github.com/<اسم-المستخدم>/meeting-minutes.git
   git push -u origin main
   ```
3. على GitHub افتح: **Settings ← Pages**.
4. في **Build and deployment ← Source** اختار **GitHub Actions**.
5. افتح تبويب **Actions** واستنى لحد ما «Deploy to GitHub Pages» يخلص (✓ أخضر).
6. رابط التطبيق هيبقى:
   ```
   https://<اسم-المستخدم>.github.io/meeting-minutes/
   ```

بعد كده، أي `push` على `main` بيشغّل الاختبارات وبيبني التطبيق وينشره لوحده.

> **ملفات مرجعية:** فولدر `templates_ref/` وأي ملفات `.docx`/`.xlsx` متضافة في `.gitignore` ومش بتترفع. متحطش أي بيانات حقيقية في الـ repo.

## 2. التثبيت على الموبايل

> **التثبيت ضروري مش اختياري.** على الآيفون بالذات، Safari ممكن يمسح بيانات أي موقع مش متثبّت لو متفتحش فترة.

### الآيفون (Safari)

1. افتح الرابط في **Safari**.
2. اضغط زر **المشاركة** (مربع وسهم لفوق).
3. اختار **«إضافة إلى الشاشة الرئيسية»** ← **إضافة**.
4. من هنا ورايح افتح التطبيق **من الأيقونة** بس، مش من Safari. البيانات جوه التطبيق المتثبّت منفصلة عن بيانات Safari.

### الأندرويد (Chrome)

1. افتح الرابط في **Chrome**.
2. اضغط زرار **«تثبيت التطبيق»** اللي بيظهر جوه التطبيق، أو من قائمة ⋮ اختار **«تثبيت التطبيق»**.

### التحديثات

لما تنزل نسخة جديدة، هيظهر شريط **«يوجد تحديث جديد»**. التحديث مش بيتطبّق إلا لما تضغط **«تحديث الآن»**، وبياناتك بتفضل زي ما هي.

## 3. النسخ الاحتياطي

> البيانات كلها على الموبايل بس. **النسخة الاحتياطية هي الطريقة الوحيدة لاسترجاعها** لو الموبايل ضاع أو اتمسح التطبيق.

### عمل نسخة

1. **الإعدادات ← النسخ الاحتياطي ← «نسخة احتياطية الآن».**
2. هيتعمل ملف واحد `نسخة_احتياطية_محاضر_YYYY-MM-DD.json` فيه كل حاجة: الجهة واللوجو، والأشخاص، والسلاسل، والاجتماعات، والمهام، والتحديثات.
3. ابعته لنفسك على واتساب أو الإيميل، أو احفظه في Files / Google Drive.
   - على الآيفون بتظهر قائمة المشاركة.
   - على الأندرويد، لو المشاركة مش متاحة للنوع ده، الملف بيتنزّل في التنزيلات.

**التذكير:** لو آخر نسخة عدّى عليها أكتر من 7 أيام، بيظهر تنبيه في الرئيسية فيه زرار نسخة مباشر.

### الاسترجاع

1. **الإعدادات ← النسخ الاحتياطي ← «استرجاع من ملف»**، واختار ملف الـ JSON.
2. التطبيق بيعرض اللي في النسخة (عدد السلاسل والأشخاص والاجتماعات والمهام وتاريخها)، ويطلب تأكيد.
3. **قبل ما يمسح أي حاجة، بيحفظ نسخة أمان تلقائية من البيانات الحالية.** لو استرجعت بالغلط، تقدر ترجع لها من: الإعدادات ← النسخ الاحتياطي ← «نسخ الأمان التلقائية» ← «رجوع للنسخة دي».

- النسخ من إصدار أقدم من التطبيق بتتحدّث تلقائياً لما تتسترجع.
- لو النسخة من إصدار أحدث، حدّث التطبيق الأول.

### نقل سلسلة لجهاز تاني

- **صفحة السلسلة ← «تصدير إعدادات السلسلة»:** ملف فيه الاسم والترقيم والتكرار والحضور والمحاور والألوان، من غير اجتماعات ولا مهام.
- **على الجهاز التاني:** الإعدادات ← «استيراد سلسلة من ملف». الأشخاص اللي موجودين بنفس الاسم بيتستخدموا، والجداد بيتضافوا للدليل.

### استيراد مهام من Excel

- **الإعدادات ← «استيراد مهام من Excel»**، والملف لازم يكون بنفس أعمدة ملف المتابعة: الرقم، المحور، المهمة، المسؤول، تاريخ الإدراج، الموعد المستهدف، الحالة، آخر تحديث، المطلوب للاجتماع القادم. وشيت «المغلق» بيتقري كمان.
- المهام بتحتفظ بأرقامها (مثلاً Y-07)، والمهام الجديدة بعد كده بتكمّل الترقيم من بعدها.
- الملف بيتقري على الموبايل بس، ومش بيتبعت لأي مكان.

## 4. القفل بـ PIN

- **الإعدادات ← قفل بـ PIN ← «تفعيل القفل»:** من 4 لـ 8 أرقام. التطبيق بيطلب الـ PIN لما يتفتح بس، وبيفتح لوحده أول ما تكتب آخر رقم صح. وطول ما التطبيق مفتوح مش بيطلبه تاني: لا لما تسحب الشاشة لتحت، ولا لما تخرج لتطبيق تاني وترجع. بيرجع يطلبه لما التطبيق يتقفل خالص ويتفتح من جديد.
- ده **قفل للواجهة بس، مش تشفير للبيانات.** الـ PIN نفسه مش متخزن، اللي متخزن بصمة مشفّرة منه (hash).
- **لو نسيت الـ PIN:** مفيش طريقة لاسترجاعه.
  1. في شاشة القفل اضغط «نسيت الـ PIN؟»، واكتب «مسح» للتأكيد. كل البيانات بتتمسح، والقفل بيتشال.
  2. استرجع آخر نسخة احتياطية من الإعدادات.

  علشان كده **خلّي عندك نسخة احتياطية حديثة دايماً.**

## 5. التصدير

- **المحضر:** من آخر خطوة في الاجتماع، أو من الأرشيف.
  - **Word:** اسم الملف `محضر_{اسم السلسلة}_{YYYY-MM-DD}.docx`، بالخط Arial، ومقاس A4، ومن اليمين للشمال.
  - **PDF:** مقاس A4، ومفيش صف جدول بيتقسم بين صفحتين، وحجمه صغير يتبعت على واتساب.
  - **طباعة:** من المتصفح.
- **ملف المتابعة لكل سلسلة:** من صفحة السلسلة، أو من المتابعة بعد ما تختار السلسلة.
  - **PDF:** بالعرض، وفيه كل المهام وآخر تحديث لكل واحدة.
  - **Excel:** فيه شيت «المتابعة» للمفتوح وشيت «المغلق»، بنفس أعمدة ملف المتابعة، والتواريخ فيه تواريخ حقيقية تقدر ترتب بيها. نفس الملف ده تقدر ترجع تستورده في التطبيق.

## 6. اللغة

- **الإعدادات ← اللغة / Language:** العربية أو English.
- الإنجليزي بيقلب الواجهة كلها من الشمال لليمين، والمحاضر (Word وPDF) وملفات المتابعة وأسماء الملفات بتطلع باللغة اللي إنت مختارها.
- الألقاب المتخزنة بتتعرض بالإنجليزي كده: م/ ← Eng.، د/ ← Dr.، أ/ ← Mr./Ms.
- اللغة بتتحفظ في النسخة الاحتياطية، فلما تسترجع على موبايل جديد بترجع زي ما كانت.

## 7. التقويم والتذكيرات

- **تقويم جوه التطبيق:** في تبويب «الاجتماعات». الأسبوع بيبدأ يوم السبت.
  - النقطة الملونة: اجتماع اتعمل أو مسودة.
  - النقطة الفاضية: اجتماع جاي محسوب من تكرار السلسلة.
  - المربع: موعد مهمة، ولونه أحمر لو متأخرة.
  - تلمس اليوم، تظهر تفاصيله تحت.
- **إضافة لتقويم الموبايل (آيفون، جوجل، Outlook):** صفحة السلسلة ← «إضافة للتقويم».
  - اختار ساعة الاجتماع والمدة والتذكير، والتطبيق بيعمل ملف `.ics` فيه الاجتماعات كحدث متكرر، أو مواعيد المهام المفتوحة بتذكير الساعة 9 الصبح.
  - **التقويم هو اللي بيبعت الإشعار**، فبيشتغل حتى والتطبيق مقفول ومن غير إنترنت.
  - **Outlook:** لما التقويم يسألك تضيفه فين، اختار حساب الشغل. أو ابعت الملف لإيميلك وافتحه في Outlook.
  - لو المعاد اتغير، ضيفه تاني.
- **تنبيهات الرئيسية:** المهام المتأخرة، واللي معادها خلال 3 أيام، واجتماع النهارده أو بكرة. كل تنبيه بيفتح المكان المناسب.
- **رقم المتأخر على أيقونة التطبيق:** من الإعدادات. على الآيفون محتاج إذن الإشعارات، والرقم بيتحدث كل ما تفتح التطبيق.
- **ليه مفيش إشعارات من التطبيق نفسه وهو مقفول؟** تطبيقات الويب مقدرتش تعمل ده من غير سيرفر، والتطبيق ده معمول من غير سيرفر علشان بياناتك تفضل على الموبايل بس.

## 8. دليل الاستخدام جوه التطبيق

- زرار **❓** في أعلى الرئيسية، أو الإعدادات ← **«دليل الاستخدام»**.
- فيه شرح خطوة بخطوة لكل حاجة: البداية والتثبيت، السلاسل، الاجتماع، المتابعة، الأرشيف، دليل الأشخاص، التصدير، استيراد Excel، النسخ الاحتياطي، الـ PIN، اللغة، والتحديث والعمل أوفلاين.
- الدليل بيتعرض بلغة التطبيق الحالية (عربي أو إنجليزي)، وتحت الخطوات المهمة فيه صورة من شاشة التطبيق نفسه (ببيانات تجريبية)، والصور شغالة أوفلاين.
- جوه شاشة استيراد Excel فيه لينك **«إزاي أستورد؟»** بيفتح الشرح بتاعها على طول.

## 9. مزايا تانية

- **جولة أول مرة:** أول ما التطبيق يتفتح بتظهر شرائح قصيرة بتشرح الأساسيات. تقدر تفتحها تاني من الدليل ← «جولة سريعة في التطبيق».
- **بحث في الدليل:** اكتب أي كلمة (PIN، Excel، حضور) وهتظهر الخطوات المطابقة بس.
- **المتابعة متقسمة حسب الموعد:** متأخرة، موعدها النهارده، باقي الأسبوع ده، بعد كده، من غير موعد.
- **رسالة واتساب للمسؤول:** اختار المسؤول في فلتر المتابعة ← «ابعت مهامه على واتساب». الرسالة بتطلع جاهزة بكل مهامه المفتوحة، وإنت بتختار الشخص.
- **تقرير المسؤولين:** المتابعة ← «تقرير المسؤولين». لكل مسؤول شريط فيه المتأخر والمفتوح والمقفول، ونسبة الإغلاق في المعاد، ومتوسط التأخير.
- **قوالب المهام:** في «مهمة جديدة» دوس «حفظ كقالب»، والمرة الجاية اختارها من «من قالب». القوالب بتدخل في النسخة الاحتياطية.
- **نسخ محاور الاجتماع السابق:** في خطوة البيانات بلمسة واحدة.
- **نسخة احتياطية سريعة:** زرار السحابة فوق في الرئيسية.
- **مقارنة قبل الاسترجاع:** قبل ما تسترجع نسخة بتشوف عدد السلاسل والأشخاص والاجتماعات والمهام دلوقتي وفي الملف، وأي سلسلة أو تعديل هيضيع.
- **الوضع الداكن وحجم الخط:** الإعدادات ← «المظهر وحجم الخط». المحضر والملفات المصدّرة بتفضل زي ما هي.

## للمطوّر

```bash
npm install
npm run dev        # تشغيل محلي
npm test           # الاختبارات
npm run build      # بناء النسخة النهائية في dist/
npm run preview    # تجربة النسخة النهائية (والـ Service Worker) محلياً
npm run icons      # توليد أيقونات PWA من public/favicon.svg (بعدها: أيقونة الآيفون والـ maskable اتعملوا من assets/icon-fullbleed.svg من غير إطار)
```

- التقنيات: Vite + TypeScript + Preact، و`vite-plugin-pwa`، والخط Cairo محزوم محلياً.
- نصوص الواجهة في `src/i18n/ar.ts` (عربي) و`src/i18n/en.ts` (إنجليزي) بنفس المفاتيح. TypeScript واختبار `tests/i18n-xlsx.test.ts` بيتأكدوا إن الملفين متطابقين.
- التواريخ بتتخزن `YYYY-MM-DD`، وبتتعرض `dd/mm/yyyy`، والأسبوع بيبدأ يوم السبت (`src/lib/dates.ts`).
- قاعدة البيانات: Dexie، والترقيات في `src/db/schema.ts` (`SCHEMA_VERSIONS`). أي نسخة جديدة لازم يتضاف لها اختبار في `tests/migrations.test.ts`.
- غيّر `version` في `package.json` مع كل إصدار، علشان رقم الإصدار والنسخة يظهروا في الإعدادات ← «عن التطبيق».
