# محاضر الاجتماعات والمتابعة

تطبيق موبايل (PWA) لإدارة الاجتماعات المتكررة: الحضور، المحاور، متابعة المهام، القرارات، وتصدير المحضر Word وPDF.

- **يعمل بدون إنترنت** بعد أول فتح.
- **كل البيانات على الموبايل فقط.** مفيش سيرفر ولا حسابات ولا أي إرسال للبيانات.
- الكود ده عام ومفيهوش أي بيانات حقيقية.

---

## 1. الرفع على GitHub وتفعيل Pages

1. اعمل repo جديد على GitHub باسم **`meeting-minutes`**، ويكون عام (Public).
2. من جهازك، جوه فولدر المشروع:
   ```bash
   git remote add origin https://github.com/<اسم-المستخدم>/meeting-minutes.git
   git push -u origin main
   ```
3. على GitHub افتح: **Settings ← Pages**.
4. في **Build and deployment ← Source** اختار **GitHub Actions**.
5. افتح تبويب **Actions** واستنى لحد ما «Deploy to GitHub Pages» يخلص (✓ أخضر).
6. رابط التطبيق هيبقى:
   ```
   https://<اسم-المستخدم>.github.io/meeting-minutes/
   ```

بعد كده، أي `push` على `main` بيشغّل الاختبارات وبيبني التطبيق وينشره لوحده.

> **ملفات مرجعية:** فولدر `templates_ref/` وأي ملفات `.docx`/`.xlsx` متضافة في `.gitignore` ومش بتترفع. متحطش أي بيانات حقيقية في الـ repo.

## 2. التثبيت على الموبايل

> **التثبيت ضروري مش اختياري.** على الآيفون بالذات، Safari ممكن يمسح بيانات أي موقع مش متثبّت لو متفتحش فترة.

### الآيفون (Safari)

1. افتح الرابط في **Safari**.
2. اضغط زر **المشاركة** (مربع وسهم لفوق).
3. اختار **«إضافة إلى الشاشة الرئيسية»** ← **إضافة**.
4. من هنا ورايح افتح التطبيق **من الأيقونة** بس، مش من Safari. البيانات جوه التطبيق المتثبّت منفصلة عن بيانات Safari.

### الأندرويد (Chrome)

1. افتح الرابط في **Chrome**.
2. اضغط زرار **«تثبيت التطبيق»** اللي بيظهر جوه التطبيق، أو من قائمة ⋮ اختار **«تثبيت التطبيق»**.

### التحديثات

لما تنزل نسخة جديدة، هيظهر شريط **«يوجد تحديث جديد»**. التحديث مش بيتطبّق إلا لما تضغط **«تحديث الآن»**، وبياناتك بتفضل زي ما هي.

## 3. النسخ الاحتياطي

> هتشتغل بالكامل في المرحلة 7.

- **الإعدادات ← النسخ الاحتياطي ← تصدير:** بيعمل ملف JSON واحد فيه كل حاجة، بما فيها اللوجو. تقدر تبعته لنفسك على واتساب أو الإيميل أو تحفظه في Files / Drive.
- التطبيق بيفكّرك لو آخر نسخة عدّى عليها أكتر من 7 أيام.
- **الاسترجاع:** قبل ما أي بيانات تتمسح، التطبيق بيعمل نسخة تلقائية من البيانات الحالية الأول.
- **لو نسيت الـ PIN:** الحل الوحيد إنك تمسح البيانات وترجّعها من نسخة احتياطية. علشان كده خلّي عندك نسخة حديثة دايماً.

## للمطوّر

```bash
npm install
npm run dev        # تشغيل محلي
npm test           # الاختبارات
npm run build      # بناء النسخة النهائية في dist/
npm run preview    # تجربة النسخة النهائية (والـ Service Worker) محلياً
npm run icons      # توليد أيقونات PWA من public/favicon.svg
```

- التقنيات: Vite + TypeScript + Preact، و`vite-plugin-pwa`، والخط Cairo محزوم محلياً.
- نصوص الواجهة كلها في `src/i18n/ar.ts`.
- التواريخ بتتخزن `YYYY-MM-DD`، وبتتعرض `dd/mm/yyyy`، والأسبوع بيبدأ يوم السبت (`src/lib/dates.ts`).
